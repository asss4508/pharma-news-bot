# 📰 제약·바이오 뉴스 자동 텔레그램 봇

## 주요 뉴스 정기 발송

`hourly_news.yml`은 한국시간 매일 08:00~16:00 정각에 실행됩니다(1시간 간격, 총 9회).
GitHub Actions 대기열 때문에 실제 발송 시각은 지연될 수 있습니다.
16시 회차의 지연 발송은 16:59까지 허용하며, 17시 이후에는 건너뜁니다.
수동 실행은 시간대와 관계없이 즉시 발송합니다.

회차마다 중복되지 않는 기업 이슈 기사 1건을 전송합니다.
매 실행 시 네이버 경제·산업 전문 매체의 '많이 본 뉴스'를 다시 조회하고,
매체별 상위 순위의 적합한 기업 기사를 우선합니다. 실시간 조회수 증가량이나
전체 언론사 통합 순위는 아닙니다. 적합한 인기 기사가 없거나 수집에 실패하면
일반 기업 기사로 대체합니다. 발행일을 확인할 수 있는 당일 기사만 선정합니다.
ETF·ETN·펀드·자산운용·수익률 홍보 및 목표주가·추천주 기사는 제외하며,
제목에서 수주·공급계약·신제품·신약·기술이전·양산·인수합병·실적 변화·리콜 등
기업 이벤트 키워드가 확인되는 기사만 후보로 선정합니다.
키워드 기반 선별이므로 제목에 사건이 드러나지 않는 기사는 누락될 수 있습니다.

형식은 `🔜 굵은 제목`, 빈 줄, 원문 앞부분 최대 3문장(650자)을 두 문단으로
발췌한 본문, 빈 줄, 전체 기사 URL입니다. 본문은 재작성하지 않습니다.
적합한 새 기사가 없으면 발송하지 않습니다.
완결된 문장을 길이 제한 안에서 추출할 수 없으면 제목과 링크만 표시합니다.
최근 90건의 제목을 순서대로 보관해 중복 발송을 방지합니다.

시간 변경은 `.github/workflows/hourly_news.yml`의 UTC cron 및 스크립트의 `in_send_window`에서,
본문 형식 변경은 `scripts/send_hourly_news.py`의 `compact_summary`와
`build_message`에서 할 수 있습니다.

매일 아침 8시, 약업닷컴 + 팜뉴스 최신 기사를 텔레그램으로 자동 전송합니다.

## ⚙️ 설정 방법 (5분이면 완료!)

### 1단계 — GitHub 저장소 만들기
1. [github.com](https://github.com) 로그인
2. 우상단 `+` → `New repository`
3. 이름 입력 (예: `pharma-news-bot`) → `Create repository`
4. 이 폴더의 파일들을 업로드 (또는 git push)

### 2단계 — 텔레그램 정보 입력 (Secrets 등록)
1. GitHub 저장소 → `Settings` 탭
2. 왼쪽 메뉴 `Secrets and variables` → `Actions`
3. `New repository secret` 버튼 클릭
4. 아래 두 개를 각각 추가:

| Name | Value |
|------|-------|
| `TELEGRAM_BOT_TOKEN` | 봇 토큰 (예: `123456:ABC-DEF...`) |
| `TELEGRAM_CHAT_ID` | 채팅 ID (예: `-1001234567890`) |

### 3단계 — Actions 활성화
1. 저장소 → `Actions` 탭
2. `I understand my workflows, go ahead and enable them` 클릭

### 4단계 — 테스트 실행
1. `Actions` 탭 → `매일 아침 제약 뉴스 전송` 클릭
2. `Run workflow` 버튼으로 즉시 테스트 가능

## ❓ 채팅 ID 모르는 경우
텔레그램에서 `@userinfobot` 에게 아무 메시지나 보내면 ID를 알려줍니다.
그룹/채널에 봇을 추가한 경우, `@getidsbot` 을 그룹에 초대하면 그룹 ID를 알 수 있습니다.
